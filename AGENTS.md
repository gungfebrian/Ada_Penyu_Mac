# Project guidance

Consult library documentation for unfamiliar APIs, version changes, uncertain behavior, or explicit documentation requests. Prefer Context7; its lookup procedure lives in the `context7-mcp` skill.

For planning, read `.agents/skills/using-superpowers/SKILL.md` first. Use `brainstorming` to settle requirements and design, then `writing-plans` to produce an implementation plan with checkable tasks. Follow explicit user decisions and retain unresolved product decisions as deferred work rather than guessing.

Keep designs in `docs/superpowers/specs/` and implementation plans in `docs/superpowers/plans/`. Respect Plan mode: present proposed changes without writing repository files until execution is enabled.

Additional Matt Pocock workflows are installed under `.agents/skills/`; `.agents/mattpocock.json` records their source and revision. Select them when relevant while retaining the Superpowers planning sequence above.
