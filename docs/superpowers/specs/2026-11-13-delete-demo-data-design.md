# Remove app Demo mode

Approved design: remove selectable Demo mode, the eight-turtle dataset and repository, demo identity defaults, and automatic sample-photo/overlay substitutions. Require sign-in for the workspace; preserve session isolation, empty states and visible API failures. Keep explicit I3S reference tools, bundled reference assets and Scientist Review prototype. Backend database deletion and reference scoring changes are deferred.

Approaches: hiding the demo entry points would leave fake runtime paths reachable; removal eliminates them. Preview-only fixtures were considered; the user selected empty-state previews instead. Test fixtures remain in the test target only.
