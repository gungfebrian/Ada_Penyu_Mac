# Compare face-scale patches in Not Sure

Add Compare scales inside Contours. The reviewer draws one patch on each same-side photo and opens proportional close-ups. Each pane supports independent zoom and pan. The Outlines toggle reveals the underlying photo even if contour extraction is incomplete.

Selections belong to the displayed photo and head side. A candidate change keeps the sighting patch and clears the candidate patch. Leaving the case clears both. A candidate refresh can reuse an older photo of the same side. The existing verdict controls remain available.
